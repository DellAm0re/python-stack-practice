# Практична робота — Стек (Stack)

Сім задач з алгоритмів і структур даних на Python 3.10+.

## Що таке стек?

Стек — структура даних за принципом **LIFO** (Last In, First Out): останній доданий елемент видаляється першим.
У Python як стек можна використовувати список: `append()` додає елемент, `pop()` видаляє останній, `stack[-1]` читає верхній.

## Основні ідеї

1. У стек кладемо відкривальні дужки; закривальні звіряємо з останньою відкритою.
2. Йдемо по лівих нащадках, знімаємо вузол зі стека, обробляємо його і переходимо праворуч.
3. Паралельно з основним стеком підтримуємо стек поточних мінімумів.
4. Перший стек приймає нові елементи; другий видає їх у зворотному порядку.
5. При `[` зберігаємо попередній текст і лічильник; при `]` розгортаємо повторення.
6. Числа додаємо до стека; оператор застосовуємо до двох останніх чисел у правильному порядку.
7. Зберігаємо індекси відкривальних дужок і базову позицію `-1` для підрахунку довжини.
